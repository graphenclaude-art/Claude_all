# Claude_all

Configuración compartida de Claude Code para este workspace.

## Skills instaladas

- **scroll-craft** (`.claude/skills/scroll-craft/`) — construye landing pages
  premium impulsadas por scroll. Instalada desde
  [nateherkai/scroll-craft](https://github.com/nateherkai/scroll-craft) (MIT).
  Se activa automáticamente cuando pides una landing "scroll-driven",
  "cinematic hero", "scrollytelling", etc. Ver
  `.claude/skills/scroll-craft/SKILL.md` para el detalle completo.
